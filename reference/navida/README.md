# Preserved Navida prototype source

These files are reference material, excluded from application TypeScript compilation and backend test discovery. They are not a second runnable app. The complete untouched original root is retained by Git tag `archive/iris-before-consolidation`; the Earth Trend source is retained by `archive/earth-trend-source-84d941f`.

The deterministic cube, durable store and automatic PASSED method labels do not establish NASA provenance or validated inference. Their runtime paths are disconnected. Layouts, map selection, editor, preview controls and analysis panels may be reused task by task after adapting the generated contracts and meeting source/scientific acceptance gates. The archived original statistics tests depend on the prototype's imports/dependencies and are not claims about the canonical backend.

Former Earth Trend shell-specific browser assertions are retained as `.spec.ts.txt` and replaced by root-layout journeys; its scientific transport/renderer regression checks remain active under `tests/`.
